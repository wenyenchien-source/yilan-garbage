# 宜蘭垃圾車幾點到

宜蘭縣垃圾車清運點與表定時間查詢網頁。免費、開源，任何人都可以自由使用、修改、部署。

## 功能

- **看整條路線**：選鄉鎮市、路線、星期，列出每一站的表定時間；今天會標出接下來要到的點。
- **用我的位置找最近的路線**：自動找出離你最近的兩條路線，並標出最近的清運點。
- **找清運點**：用定位或輸入路名、地標搜尋。
- **我的清運點**：收藏自家的點，打開就看到「表定還有幾分鐘」（存在使用者自己的瀏覽器裡）。
- 自動處理全縣週三、週六停收，以及站名裡註記的「一、五行駛」「寒暑假停駛」等規則。

所有時間都是**表定時間**，不是即時位置。

## 檔案說明

| 檔案 | 用途 |
| --- | --- |
| `index.html` | 網站本體，單一檔案，資料已嵌入，直接部署即可 |
| `template.html` | 網頁樣板（改畫面、改功能請改這個） |
| `data/ILEPB04004.csv` | 環保局開放資料原檔 |
| `tools/build_data.py` | 把 CSV 整理後嵌入樣板，產生 `index.html` |

## 更新資料

1. 到政府資料開放平台下載最新 CSV：<https://data.gov.tw/dataset/128901>
2. 覆蓋 `data/ILEPB04004.csv`
3. 執行（第二個參數填資料集頁面上的更新日期）：

   ```
   python3 tools/build_data.py data/ILEPB04004.csv 2025-06-20
   ```

4. 把新的 `index.html` 推上 GitHub，Vercel 會自動重新部署。

## 部署

這是純靜態網頁，不需要伺服器或金鑰。可放在 Vercel、GitHub Pages、Netlify 或任何網頁空間。
注意：手機定位功能需要 `https://` 網址才能使用。

## 原始資料已知問題（建置時已自動處理）

- CSV 的「星期」欄位幾乎每站都列出一到日，實際停收規則寫在清運點名稱的括號裡，程式改從名稱解析。
- 礁溪鄉路線三「福德廟、石板橋頭」一筆因名稱含逗號造成欄位錯位，程式已修正座標。
